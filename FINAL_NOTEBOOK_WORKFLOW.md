# Final HE3027 notebook workflow

Run these notebooks in order, using **Run all** in each:

1. [crime_housing_project_analysis.ipynb](crime_housing_project_analysis.ipynb): original-data exploration, monthly-source audit, geographical checks, annual/previous-year/prior12 construction, and export to `data/crime_housing_merged.csv.gz`.
2. [01_crime_original.ipynb](01_crime_original.ipynb): original current-calendar-year (`annual`) and previous-calendar-year (`lagyear`) crime on the same sales, each with the full M1-M7 sequence. Outputs are together in `data/01_crime_original_outputs/`.
3. [02_crime_mps.ipynb](02_crime_mps.ipynb): reconstructed MPS current-year, previous-year, and prior12 panels, each with the full M1-M7 sequence.
4. [03_crime_mps_income_interaction.ipynb](03_crime_mps_income_interaction.ipynb): M7-only MPS prior12 crime-by-borough-income interaction models with all five location controls, LSOA and year-quarter fixed effects, and sample/interaction/slope figures. Gross annual pay is a borough-level proxy, not household income.
5. Exploratory IV extension: [04_crime_iv_exploratory.ipynb](04_crime_iv_exploratory.ipynb) displays only the nine M7 combinations of three MPS crime types and three exposure windows, using days reaching 25°C as a candidate instrument. Set `RUN_MODELS = True` in the notebook to rerun only those nine fits, or run `python -m utils.temperature_iv_m7` from the project root. The underlying Open-Meteo daily and monthly files are in `project_data/temperature/`; [utils/fetch_open_meteo.py](utils/fetch_open_meteo.py) retrieves and verifies the daily values. The pilot uses coarse reanalysis weather; the higher-resolution HadUK-Grid archive requires a CEDA login. Heat may directly affect prices, so the IV estimates are diagnostic rather than causal.
6. [05_crime_quantile.ipynb](05_crime_quantile.ipynb): exploratory conditional quantiles using a reproducible 6,000-sale MPS prior12 sample, directly included borough/quarter indicators, clustered bootstrap intervals and a matched OLS benchmark. Increase `MAX_SALES` and `BOOTSTRAP_REPS` for final inference. Ordinary TWFE demeaning is not used for quantile regression.
7. [06_crime_spatial_autocorrelation.ipynb](06_crime_spatial_autocorrelation.ipynb): representative LSOA sale-location coordinates, great-circle distances, 4/8/12-neighbour weights, quarterly Moran diagnostics based on transaction-level M7-style price residuals, and prior12 crime SLX regressions. Coordinates are not official centroids. Spatial dependence and crime endogeneity remain substantive limitations.
8. [07_crime_results_analysis.ipynb](07_crime_results_analysis.ipynb): MPS-first coefficient/significance heatmaps, M6-to-M7 intervals and residual crime SDs, and changes relative to M2 for all three MPS exposures. The original-source results are a secondary comparison. Exports a tidy M2-M7 table and figures to `data/07_crime_results_outputs/`. Run notebooks 01 and 02 first. Original prior-12-month estimates are not available in the primary model outputs.
9. [08_crime_original_robustness.ipynb](08_crime_original_robustness.ipynb): full M1–M7 endpoint sensitivity on common 2012–2014 sales and a full pre-2014 rerun on common 2012–2013 sales for both original crime timings. Its three-sample M2–M7 heatmap shows coefficients and significance; supporting CSVs and figures go to `data/08_crime_original_robustness_outputs/`. Run notebook 01 first.

Notebooks 05 and 06 can each run directly after the audit; they do not require the other regression notebooks to execute. Their outputs are saved in the corresponding `data/05_crime_quantile_outputs/` and `data/06_crime_spatial_outputs/` folders. They adapt ideas from the cited paper rather than claiming exact replication or guaranteed causal identification.

In Colab, the project folder is `/content/drive/MyDrive/HE3027 Project`; put both original input files directly in its `data/` folder. Locally, the audit also accepts inputs in `project_data/` or the project root. Temperature source data are in `project_data/temperature/`, and the cached ONS 2011 LSOA boundary polygons are in `project_data/boundaries/`. [utils/fetch_lsoa_2011_boundaries.py](utils/fetch_lsoa_2011_boundaries.py) retrieves the boundary file, and notebook 06 loads it from that folder. Generated charts and result tables go in `data/`.

The main regression notebooks include their analysis helpers. Notebook 04 reads saved M7 IV outputs by default and reruns the nine models when requested or when its result CSV is missing; source weather files are kept separately from result tables. Notebook 07 reads the saved primary regression outputs; notebook 08 reads the audit's merged data and notebook 01's saved results. Reusable scripts, including [utils/run_notebooks.py](utils/run_notebooks.py) and [utils/plot_lsoa_neighbours.py](utils/plot_lsoa_neighbours.py), are in `utils/`.

## Final model numbering

M1: property only. M2: add crime. M3: add location and economic controls. M4: add local-authority and year effects. M5: replace local-authority with MSOA effects. M6: replace year with year-quarter effects. M7: replace MSOA with LSOA effects. This numbering supersedes earlier reconciled models and separates the addition of controls from the addition of fixed effects.

The primary panels omit job density to retain 2015 and include pay, hours and unemployment. Set `RUN_STRICT = True` in an analysis notebook to add a separately reported panel with job density. Current-year and previous-year original panels share the same sales; all three MPS exposures share the same sales. Original and MPS panels have different coverage and should not be compared as a pure timing experiment.

Recorded zero is retained. Missing is not converted to zero. Original violence is all zero in 2014-2015 and endpoint all-crime counts are anomalously low; original-source results require caution. MPS categories are not assumed identical to the original definitions.

Every estimated specification is saved, with LSOA-clustered confidence intervals, individual control coefficients and coefficient-path figures. Estimating a negative association is not a criterion for selecting a model.
