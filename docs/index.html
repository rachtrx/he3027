How to interpret comparisons

Standard errors are clustered by LSOA for all main regressions, including the basic specifications. The temperature IV rows use weather-cell clustering. * “Requires IV?” is a conditional endogeneity-test readout for the selected temperature threshold; temperature is not a validated instrument. A dash means unavailable; results describe associations unless a valid causal design is established.

25°C diagnostics · all crime types

M7 first stages and conditional Wooldridge endogeneity tests for all crime, violent crime and property crime on the same 338,347 sales. Standard errors are clustered by the 21 distinct weather-source locations.

A Wooldridge p-value below 0.05 rejects the exogeneity null only if the temperature instrument is valid. A first-stage F below 10 flags a weak instrument. Neither test establishes that temperature affects prices only through crime.

Quarterly spatial autocorrelation · appendix tables

Moran’s I uses complete sale quarters and 4, 8 or 12 neighbours. A star (*) after a Moran value means its permutation p-value is below 0.05; the adjacent column reports that p-value to four decimal places. With 199 permutations, 0.0050 is the smallest possible p-value. Residual p-values are exploratory because the residuals are estimated. The July-only 2015Q3 is excluded. Residuals come from transaction-level own-crime models with LSOA and year-quarter fixed effects, then are averaged within LSOA-quarter. The LSOA count varies by quarter.

The earlier residual range 0.077–0.081 (p = 0.005) described an annual aggregated analysis. In these quarterly M7-style diagnostics, residual Moran’s I ranges from −0.0164 to 0.0879. Of 126 crime-type × quarter × neighbour results, 78 are positive with p < 0.05; none of the negative values has p < 0.05.
