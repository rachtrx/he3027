How to interpret comparisons

Standard errors are clustered by LSOA for all main regressions, including the basic specifications. A dash means unavailable; results describe associations unless a valid causal design is established.

IV endogeneity checks

This is not a test of whether the instrument is valid. The null is that residential burglary is exogenous conditional on controls and fixed effects. The primary result is the LSOA-clustered Wooldridge regression test. Rejection suggests an endogeneity concern only if the instrument is valid. Neither rejection nor non-rejection verifies the instrument’s exclusion restriction.
